# Počítačové sítě & Protokoly TCP/IP — Výukový portál

Interaktivní webový výukový portál vytvořený pro výuku a samostudium počítačových sítí.

## Obsah portálu
- **[OP — Obecné principy počítačových sítí](./op/)**: 7 modulů, 18 kapitol, 18 interaktivních laboratoří, 18 dabovaných videí (topologie, Ethernet, VLAN 802.1Q, routování, NAT/PAT, firewall stateless/stateful/NGFW, SDN, Wi-Fi).
- **[OP — Protokoly TCP/IP](./tcp-ip-protokoly/)**: 6 modulů, 16 kapitol, 16 interaktivních simulátorů, 16 dabovaných videí a přehled TCP/UDP portů (TCP/UDP, RIP/OSPF/BGP, DNS, DHCP, NTP, HTTP/S, SMTP/IMAP/POP3, FTP aktivní/pasivní & FTPS, Samba/SMB, SSH/Telnet/SFTP, RDP/VNC, SNMP/Syslog, SIP/RTP/WebSocket/MQTT).
